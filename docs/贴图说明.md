# 贴图说明 · Texture Guide

本项目用到的全部图片资产：**43 张可平铺材质 + 30 张城镇设施贴图 + 621 个精灵 + 4 张植物图集**。
全部由 AI 生成（dashscope `qwen-image-3.0`）后经本地脚本处理（切分、抠图、量接缝），
风格统一为 **吉卜力背景美术 × 《蜡笔小新 煤炭镇的小白》插画质感**：平涂色块、手绘笔触、清晰墨线、暖调光线。

> **路径约定**：下表里的路径都相对仓库根目录。
> `public/textures/**` 是**游戏实际加载**的；`assets/**` 是**素材库**（未接入代码，供后续使用或另作他用）。
> 原始未处理的图与中间产物在仓库外的 `dsh-image-gen/`，未提交。

## 四、生成与重跑

所有贴图由 **dashscope `qwen-image-3.0`** 生成，提示词统一带这几个关键约束：

- `seamless tileable ALBEDO texture`（材质要无缝、是固有色）
- **`FLAT EVEN UNIFORM LIGHTING, no shadows, no highlights, no vignette, no gradient`** ← 这一句最关键，否则光照会被画进图里，接进 cel 着色器就变成双重打光
- `hand-painted gouache brushstrokes, Studio Ghibli background art and Crayon Shin-chan Coal Town illustration style`
- `top-down orthographic`、`no text, no border`（避免乱码字母）
- 精灵类额外加 `on a solid flat magenta #FF00FF chroma key background`

处理脚本在仓库外 `dsh-image-gen/`（未提交，可按需取用）：

| 脚本 | 作用 |
|---|---|
| `make-albedo-v2.py` | 材质：按结构选镜像/混合、量接缝、出对照表 |
| `make-shopfront.py` | 城镇设施 30 张，同上 |
| `slice-fish.py` / `slice-farm.py` / `slice-orchard.py` | 图集页切分成独立精灵（连通块 + 反预乘抠边） |
| `pack-atlas.py` | 把精灵打回图集 + UV 表 |
| `slice-plants.py` / `make-sprites.py` | 植物精灵、主角立绘 |

**判据（每批都过）**

- 材质：X 接缝 0.00，Y 接缝 ≤ 6.8/255
- 精灵：品红残留 0%，无过小残片

## 五、使用注意

1. **`assets/**` 里的东西没有接进代码**。游戏实际加载的只有 `public/textures/albedo/`、`public/textures/plants/`、`public/figures/`。
2. **区分两类贴图**：
   - **可平铺材质**（albedo 43 张、shopfront 的水泥/砖/路面/瓷砖等）→ 大面积反复平铺；
   - **门面图**（`shop_*` 7 张、`church_glass`）→ 有具体内容，平铺会重复，应贴在单块面片上。
3. **镜像无缝的代价是对称**。墙面、雪地、草坪这类各向同性材质看不出来；但如果你发现某张有明显镜像感，可以用原始 1024 图 + 偏移混合版（在 `dsh-image-gen/` 里保留）。
4. **精灵不是 3D 模型**。它们是 256×256 透明立牌/图标，适合 billboard、物品栏、图鉴；要 .glb 需要过 Tripo / Meshy / Hyper3D 这类图生 3D。
5. 图片全部走 **Git LFS**，克隆前请确认装了 `git-lfs`。

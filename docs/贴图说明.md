# 贴图说明 · Texture Guide

本项目用到的全部图片资产：**1790 个 PNG**
（293 张材质/贴图 + 1484 个精灵 + 6 张植物图集 + 7 张主角立绘），另有 16 张对照表。
全部由 AI 生成（dashscope `qwen-image-3.0`）后经本地脚本处理（切分、抠图、量接缝），
风格统一为 **吉卜力背景美术 × 《蜡笔小新 煤炭镇的小白》插画质感**：平涂色块、手绘笔触、清晰墨线、暖调光线。

> **路径约定**：下表里的路径都相对仓库根目录。
> `public/textures/**` 是**游戏实际加载**的；`assets/**` 是**素材库**（未接入代码，供后续使用或另作他用）。
> 原始未处理的图与中间产物在仓库外的 `dsh-image-gen/`，未提交。
> 图片全部走 Git LFS，克隆前请确认装了 `git-lfs`；当前 LFS 已用约 154 MB。

## 十、生成与重跑

所有贴图由 **dashscope `qwen-image-3.0`** 生成，提示词统一带这几个关键约束：

- `seamless tileable ALBEDO texture`（材质要无缝、是固有色）
- **`FLAT EVEN UNIFORM LIGHTING, no shadows, no highlights, no vignette, no gradient`** ← 这一句最关键，否则光照会被画进图里，接进 cel 着色器就变成双重打光
- `hand-painted gouache brushstrokes, Studio Ghibli background art and Crayon Shin-chan Coal Town illustration style`
- `top-down orthographic`、`no text, no border`（避免乱码字母）
- 精灵类额外加 `on a solid flat magenta #FF00FF chroma key background`

处理脚本在仓库外 `dsh-image-gen/`（未提交，可按需取用）：

| 脚本 | 作用 |
|---|---|
| `make-albedo-v2.py` | 材质：按结构选镜像/混合、量接缝、出对照表 |
| `make-roads.py` | 路面 150 张，同一套管线（14 组分类命名） |
| `make-containers.py` | 容器 70 张，同一套管线（7 组分类命名） |
| `slice-transport.py` / `slice-stations.py` / `slice-infra.py` / `slice-birds.py` | 交通 200 / 站台 500 / 基础设施 100 / 鸟类 300 的图集切分（按页配置行数） |
| `make-shopfront.py` | 城镇设施 30 张，同上 |
| `slice-fish.py` / `slice-farm.py` / `slice-orchard.py` | 图集页切分成独立精灵（连通块 + 反预乘抠边） |
| `pack-atlas.py` | 把精灵打回图集 + UV 表 |
| `slice-plants.py` / `make-sprites.py` | 植物精灵、主角立绘 |
| `append-paths.py` | 重新生成第九节的完整路径附录 |

**判据（每批都过）**

- 材质：X 接缝 0.00，Y 接缝 ≤ 8.0/255
- 精灵：品红残留 0%，无过小残片

## 十一、使用注意

1. **`assets/**` 里的东西没有接进代码**。游戏实际加载的只有 `public/textures/albedo/`、`public/textures/plants/`、`public/figures/`。
2. **区分两类贴图**：
   - **可平铺材质**（albedo 43 + 路面 150 + 容器 70 + shopfront 的砖/水泥/瓷砖等）→ 大面积反复平铺；
   - **门面图**（`shop_*` 7 张、`church_glass`）→ 有具体内容，平铺会重复，应贴在单块面片上。
3. **路面这 150 张是同一个世界的"地面词汇表"**。挑的时候按地形语义选（`earth_*` 走乡野、`brick_*`/`heritage_*` 走老城、`asphalt_*`/`urban_*` 走现代、`industry_*` 走煤炭镇），别只挑好看的——路面混搭会立刻毁掉街区的年代感。
4. **容器 70 张是"表面的皮"，不是容器模型**。`crate_*` 贴木箱六个面、`barrel_*` 卷木桶一圈；做桶时记得桶身贴图用 `barrel_*`、桶顶用 `barrel_head`。
5. **精灵三批的摆法不一样**：
   - `transport/` **侧视朝左 + 底边对齐**，直接放路上就对；
   - `stations/`、`infra/` **正视 + 底边对齐**，当地面家具摆；
   - `birds/`、`fish/` **居中**，因为它们是悬空的。
6. **镜像无缝的代价是对称**。墙面、雪地、草坪这类各向同性材质看不出来；但如果你发现某张有明显镜像感，可以用原始 1024 图 + 偏移混合版（在 `dsh-image-gen/` 里保留）。
7. **精灵不是 3D 模型**。它们是 256×256 透明立牌/图标，适合 billboard、物品栏、图鉴；要 .glb 需要过 Tripo / Meshy / Hyper3D 这类图生 3D。
8. 图片全部走 **Git LFS**（当前约 350 MB），克隆前请确认装了 `git-lfs`；克隆会拉全部图片，只想看代码可以 `GIT_LFS_SKIP_SMUDGE=1 git clone`。

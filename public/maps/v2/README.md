# 地图 v2（GPT-image-2.5 重绘）

用 `gpt-image-2.5` 重画的一套地图，画风为手绘水粉＋吉卜力／煤炭镇小白。
**旧的 `public/maps/town.jpg`、`world.jpg` 原样保留，未改动**，两套并存便于对比。

## 做法

不是让模型自由发挥，而是**先画母图，再从母图上裁区域重绘**：

```
00-world-master.png        ← 母图，一次性画出整块地理
        │
        ├── 裁出小镇核心 → 重绘 → 01-ai-town.png
        ├── 裁出雪山     → 重绘 → 02-snow-mountain.png
        ├── 裁出海岸     → 重绘 → 03-seaside.png
        └── 裁出农田湖   → 重绘 → 04-farm-lake.png
```

因为子图是母图的**同一块像素**重绘而来，所以「AI 小镇是全域图的一部分」
和「街道、河道、海岸线走向一致」是流程保证的，不依赖模型记忆。

## 标注是怎么定位的

生成模型看不到「第几号商铺在哪个像素」，所以标注不是猜坐标：

1. 用 HSV 把图分割成 水 / 雪 / 林 / 田 / 屋顶 / 沙 六类；
2. 每类做粗网格连通块分析，取最大块的中心与包围盒；
3. 自然地貌的标签直接落在检出中心上，城镇设施按屋顶簇的包围盒相对排布。

检出结果（母图）：

| 地貌 | 位置 | 像素占比 |
|---|---|---|
| 雪山 | 右上 (89%, 5%) | 2.7% |
| 森林 | 左上 (15%, 27%) | 14.8% |
| 农田 | 中下 (47%, 74%) | 30.2% |
| 水域 | 左下 (19%, 80%) | 19.2% |
| 沙滩 | 右侧 (84%, 65%) | 10.8% |
| 屋顶簇 | 中上 (52%, 30%) | 3.7% |
